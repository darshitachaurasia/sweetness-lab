How the demo calculates the result

The demo averages the six counts and scales that average to 0–100 (average × 100 / 65,535) to obtain Intensity. Illustrative linear model: 10.40 + 2.20 × (Intensity − 50)/20. The weights are chosen for demonstration. The 120-apple spectral dataset requires a separate trained model.

Demo grade thresholds: A ≥ 15, B ≥ 12, C ≥ 9, D ≥ 6, Below D < 6.

SYSTEM DESIGN

How the system works

Fetch and validate

Flask requests the latest sensor record using Requests. It checks the JSON response, extracts the sensor values, and validates that all required fields are present and numeric.

Prepare and predict

Pandas builds a row in the saved feature order. The training-time scaler transforms inputs when required, and the trained scikit-learn model estimates sweetness.

Grade and return

The app maps the score to a quality grade and returns the result, model name, and timestamp. The dashboard and API expose the same prediction.
